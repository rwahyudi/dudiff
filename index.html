Report format and limits

The page needs HTTPS or localhost for persistent local storage. A 16 GB archive is read in chunks; browser quota and available disk space still determine whether it can be indexed.

Local snapshot comparison

See where disk usage changed.

Choose a baseline and a later snapshot in the navigation panel, then process them locally. Reports stream into browser storage; no filesystem data leaves this page.

GDU JSON export

Preferred for exact file and directory counts, extensions, and modification ages.

gdu -o snapshot.gdu.json /pathgdu -o- /path | gzip -c > snapshot.gdu.json.gz

GNU DU export

Use a NUL-delimited, byte-sized export. Leaf paths are reported as unclassified.

LC_ALL=C du --all --block-size=1 --null --time --time-style=+%s /path > snapshot.du0
